What you are looking at

  • The server processes the first 64 frames of the sample clip so a request finishes while you wait.
  • Unique counts are keyed on track identity, not raw boxes. If a person is seen on 20 frames, that is one object.
  • Privacy redaction runs before the video is written. Haar cascades are not in this OpenCV build; fallback regions are used.
  • The first click after idle can take about a minute: Fly stops the machine when nobody is using it, then the model loads.
  • Precision, recall, and mAP are not quoted — this clip has no ground-truth labels.
